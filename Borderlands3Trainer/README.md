# Borderlands 3 简易修改器

这是一个仅面向《无主之地 3》离线单人游戏的 Windows 修改器。界面只要求填写
目标值并点击“修改”，不会要求输入或查看内存地址，也没有“修改前/修改后”两组输入框。

## 功能

- 现金：设置为指定目标值
- 镒矿：设置为指定目标值
- 经验值：设置为指定目标值
- 技能点：设置为指定目标值
- 金钥匙：设置为指定目标值
- 无限弹药：可随时启用或关闭
- 技能点不减少：可随时启用或关闭
- 快速移动：选择原速、2 倍、3 倍；仅修改当前玩家的地面移动倍率
- 高级武器掉落：读取当前紫/橙权重系数，输入数值调整，可恢复修改前值

## 高级武器掉落（2026-09-20 新增）

进入“高级武器掉落”页，点击“读取当前值”，再分别输入紫色（史诗）、橙色（传奇）的目标
权重系数，点击“应用目标系数”。支持 0～1000 的有限数字和小数。输入框默认 5/10 只是示例，
不会自动应用。首次定位约需一分钟，之后每秒刷新少量已定位数据，不持续扫描全部内存。

显示的是实际读到的 `Weight.BaseValueScale`，**不是爆率百分比**。橙色输入 10 表示将系数
设为 10，不是 10%，重复应用不累乘。0 会禁用该池中相应档位。游戏不存在适用于所有敌人和
箱子的统一爆率；品质选择还受动态属性与上下文影响。简单加权选择的占比取决于该档有效权重
除以所有候选有效权重之和，因此两档同时提高也会相互竞争。程序不执行完整属性求值，
不会显示未经验证的估算概率。

本功能仅改已加载的 `/Game/GameData/Loot/ItemPools/Guns/ItemPool_Guns_All` 普通武器池中
紫色和橙色两档的权重系数，保留白/绿/蓝。它影响引用此池生成的新武器的品质选择，不增加
物品等级、伤害、数量，不修改已生成的武器。Boss 专属、任务、DLC 等独立池可能不受影响，
也不解除等级、混乱模式或 DLC 限制。这是当前游戏进程中的共享掉落池，仅用于离线单人。

“恢复修改前值”、正常关闭、或“关闭全部开关”会恢复本次首次修改前的系数。若游戏/其他
工具改动了数值，程序保留外部变化并提示，不强制覆盖。切地图造成掉落池卸载或替换后，
需重新读取和应用。不要同时运行多个修改器修改同一属性；异常结束时重启游戏清除残留修改。

实机记录：`tools/loot_integration_validation.json`。当前五档系数起初均为 1，紫/橙设为
5/10 后等待 2 秒读回一致，恢复后全部与原值相同。**已验证定位、读写和恢复，尚未完成
大样本实际掉落统计与跨地图实测。** 23 项单元测试通过，覆盖输入校验、失败回滚、外部
更新、对象替换和恢复重试。

参考公开 [Better Loot 生成器](https://github.com/BLCM/bl3mods/blob/master/Apocalyptech/loot_changes/better_loot/gen_better_loot.py)
中的稀有度权重与独立掉落池机制；具体池条目、属性类型和数值在本机当前游戏中重新读取确认。

## 快速移动（2026-09-20 新增）

进入离线单人角色场景后，点击“2 倍速度”或“3 倍速度”。第一次定位需要约 30～90 秒，
完成后可以直接切换倍率；3 倍始终相对启用前的原速，不会在 2 倍基础上再乘 3。

保持修改器运行时，无需切出游戏：

- `Ctrl+Alt+1`：恢复原速
- `Ctrl+Alt+2`：2 倍速度
- `Ctrl+Alt+3`：3 倍速度

快捷键如被其他程序占用，界面会提示，仍可使用按钮。首次定位期间再次按快捷键，
程序将在当前操作完成后执行最后一次选择。正常关闭修改器或点击“关闭全部开关”会恢复速度。

本功能通过游戏的对象/属性表确认本地玩家，只写入其 `MaxGroundSpeedScale.Value`，
不修改敌人、载具或全局时间，不使用移动代码补丁。启用后每秒检查一次少量对象和数值，
不会持续全内存扫描或强制锁定速度。切地图、角色变化、上车或游戏重新计算该属性时会停止
加速，进入步行场景后重新选择倍率即可。异常结束修改器时需重启游戏清除未恢复的内存值。

已在本机当前兽王角色验证 1→2→3→1 切换及恢复：2 倍实测水平速度约 1448，3 倍约 2160。
完整动态定位后再测 2→3→1，原值恢复读回一致。跨地图/其他职业的实机测试仍未完成；
相关对象切换、属性变动和恢复失败路径由单元测试覆盖。

数值功能先读取本机 BL3 存档中的当前值，并在游戏内存中自动确认对象结构；如果存档值
已经落后于游戏状态，则使用当前游戏版本的唯一 AOB 特征码进行短时捕获。绝对内存地址
不会显示，也不会跨游戏进程保存。每次写入前校验旧值，写入后立即读回验证。

## 使用方法

1. 备份 `文档\My Games\Borderlands 3\Saved\SaveGames`。
2. 只进入离线单人游戏并载入角色。
3. 启动 `dist\BL3Trainer_CN.exe`，在 UAC 窗口中允许管理员权限。
4. 输入目标值，点击对应的“修改”；首次自动定位可能需要数秒。
5. 无限弹药、技能点不减少可直接勾选；关闭修改器时会自动恢复这两处代码补丁。

经验值修改后，游戏界面可能要等下一次获得经验或刷新角色界面才更新。若游戏或修改器
异常退出，重新启动游戏即可恢复所有代码字节。写入日志位于：

```text
%LOCALAPPDATA%\BL3Trainer\logs\writes.jsonl
```

## 检查结果和限制

- 原六组功能特征已验证唯一匹配；移动与掉落另共用两组已验证的对象表/名称表定位特征。
- 运行模块和游戏目录中未发现 EasyAntiCheat、BattlEye 或同类组件；只发现 Steam 覆盖层
  及普通外设组件。主程序导入了 `IsDebuggerPresent`，但这也是 Unreal 崩溃/调试支持的
  常见 API，单独出现不能证明游戏在检测修改器。
- 本工具不绕过反作弊、不注入 DLL、不修改游戏安装文件，也不支持联机使用。
- 游戏更新后，若特征不再唯一或原始字节不同，工具会拒绝写入，而不是猜测地址。

## 构建

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

构建脚本先执行单元测试，再通过 PyInstaller 生成请求管理员权限的单文件 EXE，并复制
配置、使用说明和功能实现对比到输出目录。界面分为常用功能/移动和高级武器掉落两页。

## 技术参考与第三方组件

移动定位参考公开 [unrealsdk BL3 布局定义](https://github.com/bl-sdk/unrealsdk/blob/master/src/unrealsdk/game/bl3/offsets.h)
和 [全局表特征定义](https://github.com/bl-sdk/unrealsdk/blob/master/src/unrealsdk/game/bl3/globals.cpp)，
运行时重新验证唯一匹配和属性名称/类型；没有安装 SDK 或向游戏注入 DLL。

只读存档解析使用 `bl3-cli-saveedit` 1.18.0，按其 zlib/libpng 许可证随项目打包。
为兼容当前 protobuf 运行时，项目内副本仅调整了 `UnknownFields()` 不可用时的兼容处理；
修改器不会调用其存档写入接口。
