# Qwen Atelier · 本地创作工作台

> Qwen Atelier — a local-first Qwen Image 2.1 studio: FastAPI backend, buildless web UI, stable-diffusion.cpp runtime, SQLite gallery, DPAPI vault, and image upscale / outpaint tools. AI-readable architecture: [ARCHITECTURE.md](ARCHITECTURE.md).

独立的 Python / FastAPI 网页，使用项目 `.venv`，不需要启动 Comfy Desktop。前端无 Node 构建依赖，无外部 CDN。

## 启动

双击项目根目录的 **启动网页.cmd**。地址固定使用 `data/settings.json` 里的 `port`（默认 `http://127.0.0.1:17860`），启动窗口会显示实际地址并打开浏览器。

- **只允许一个实例**：如果该地址上已经有本工作台在运行，启动程序只打开浏览器然后立刻退出，不会启动第二个服务，也就不会重复加载模型、不会出现两套互不知情的生成队列。之前用 `--port` 启动、或地址文件指向别的端口时，也会先找到正在运行的那个实例，并把 `data/server-url.txt` 修正过来。
- **端口被其他程序占用时不换端口**：打印占用提示并以退出码 1 结束，避免"换个端口再起一个实例"。请关闭占用该端口的程序，或修改 `data/settings.json` 的 `port`（先关掉旧窗口）后重试。
- 关闭窗口或按 Ctrl+C 停止服务；正常退出会删除 `data/server-url.txt`。

也可以在项目目录运行：

```powershell
.\.venv\Scripts\python.exe run.py
# 不自动打开浏览器：
.\.venv\Scripts\python.exe run.py --no-browser
```

依赖离线复装：`powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install_dependencies.ps1`。

## 电池保护与组件管理（2026-10-22 已部署）

设置中的电池供电保护默认开启：切换到电池时取消加载、当前生成与队列，释放本工作台模型；电池期间阻止新的加载和生成，插电后不自动重试。后台每秒监测，关闭网页也生效。台式机完全断电无法执行保护。电源事件已通过模拟验证，未实际拔掉电源。

「模型与显存」四张组件卡片提供独立加载 / 释放权重按钮，显示实际权重缓冲区占用。首次仍需组合路径齐全，用于创建共享上下文和读取元数据；只读入选择的组件权重。生成时按需补齐，释放一个组件不释放其他组件权重；mmap 模式不支持此操作。

已真实验证 Q6_K 的四组件加载 / 释放、整套预加载后的独立释放，以及释放文本编码器后在同一进程内自动补齐并生成 16bit 图片。详见 `MODEL_LIFECYCLE.md`。

## 16 bit 生图（2026-10-22 已实测）

已部署基于 `0518b34` 的本地 PNG16 补丁，复用同版本原有 CUDA 动态后端。Q6_K 实际生成验证通过：512×512、8 步、seed 20261022；原生生成耗时 21.716 秒，含模型哈希等步骤的任务总耗时约 33.2 秒。此耗时只代表本次配置与当时机器状态。

使用：展开「模型与精细参数」，在输出色深中选择「16 bit / 通道」，再开始生成；模型未加载时也可以提前选择，生成时加载引擎后验证支持情况，不支持就明确报错，不会自动降级为 8 bit。卸载模型、轮询状态、回填历史或预设都保留明确的 16 bit 请求；仅选择色深不会加载模型。原图保存为 `outputs/*_16b.png`，网页展示独立的 8 bit 预览；详情可以下载 16 bit 原图或导出 8 bit。已有的 8 bit 原图不能恢复为真正的高精度 16 bit 输出，需要重新生成。

输出链路为 VAE 浮点样本 → uint16 → PNG16，不经过 uint8 转换。实际图片经独立解压检查，RGB 各通道包含数万个不同数值；下载和 16 bit 导出与原图逐字节一致。16 bit 文件色深不代表模型具有 16 个有效精度位，也不等于增加画面分辨率或细节。验证产物保存在本地，不随仓库提供。

## 私密库（本地全加密，2026-10-23）

旧版私密库只把图片加密成副本，原图、缩略图、预览图和同名 JSON 仍留在磁盘上，普通看图软件可以直接打开。现已改为**只保留加密文件**：加密写入成功后回读校验，校验通过才删除明文原图、同名配置 JSON、缩略图、预览图与回收站副本，删除图库记录后 VACUUM 压缩数据库；如果任一步校验失败，明文原样保留并在界面报错。

**首次升级**：打开「私密库」，设置一次新密码（≥12 字符，需牢记），勾选确认后点「验证并升级全部旧文件」。升级成功后这条密码会自动保存，之后加密和查看都不再询问。升级先对全部加密文件做完整性预检，只要有任何一个文件打不开就不改动任何东西；勾选「若个别旧文件确实无法解锁，保留它们并继续升级其余文件」可以跳过这类文件——它们保持加密、不会被删除，也不能在页面查看，且不再计入待升级数量。写入新密文后才清理明文，中断或断电可用同一新密码重试。

**日常使用**：加密 = 点一下「加密」；查看 = 在私密库点「查看」。密码只在第一次（或清除保存后）需要输入。私密库页面的「设置 / 更换密码」会把全部私密文件重新加密到新密码，「清除保存的密码」让本机不再记住它，之后恢复手动输入。密码用当前 Windows 账户的 DPAPI 加密保存（`data/vault.key`），拷到别的电脑或别的 Windows 账户都无法解开。

**实测（2026-10-23，副本预演）**：`tests/vault_dryrun.py` 把真实的数据库、28 个加密文件和 186 个明文文件复制到 `.tmp/` 下（源数据只读）执行同一套迁移逻辑：27 个文件升级成功并逐个用新密码解密、与原图 SHA256 一致；1 个 4.6 MB 的旧文件因密码无从得知被保留；明文原图 / 缩略图 / 预览图 / 同名 JSON 残留 0 个，数据库残留记录 0 条，旧密码本已删除。真实图库仍保持升级前状态，等你在网页上填新密码后才执行。

**事后核查**：`.\\.venv\\Scripts\\python.exe scripts\\audit_private_plaintext.py` 只读扫描 `outputs`、`图片`、缩略图、预览图、回收站、参考图和数据库，列出仍可直接打开的私密明文（迁移前为 27 套，迁移后应为 0）。

**边界**：不处理应用之外的副本或备份；不清理 Windows 缩略图缓存、回收站历史或磁盘残留；忘记密码无法恢复。加密不改变图片内容，也不等于安全擦除工具。

## AI 放大与 AI 扩图（2026-10-23 已接线）

侧栏新增「AI 放大」「AI 扩图」两个独立入口，与生图共用同一个后台任务队列和 GPU 互斥，不会无协调并发。

两个页面顶部均提供「加载模型」「释放模型」；正在加载时可「取消加载并释放」。直接开始任务也会检查资源并自动加载。资源不足时不启动模型或入队，显示缺口与「取消本次操作」，保留图片和参数。扩图与生图共用 Qwen，释放扩图模型会释放生图组件；放大独立释放，不影响 Qwen。放大模型可在任务完成和网页服务重启后保留，修改 tile 会重新加载放大上下文。资源预算是保守估计，不保证所有尺寸都能完成；正式任务已接入低内存紧急停止。

常驻放大新增验证：128×128 → 512×512，连续两次使用同一 PID；隔离 API 手动加载、出图、网页服务重启复用和释放均通过。旧 8K 性能记录来自 CLI 路径，常驻路径尚未重测 8K。

- **AI 放大**：使用独立常驻进程调用本地 `stable-diffusion.dll` C API 与 `models/upscalers/RealESRGAN_x4plus_anime_6B.pth`（SHA256 `f872d837…`）。128×128 实测 0.76 秒输出 512×512；1080p→8K UHD 实测约 29 秒。运行条件：显卡利用率 ≤85%、内存和显存满足当前参数的保守预算、有足够磁盘空间。资源充足时允许 Qwen 与放大模型同时常驻；运行前不再强制卸载 Qwen。参数为 tile size（64–384，32 的倍数）与 repeats（1–2），输出独立目录 `outputs/upscale/<任务 ID>/`，不覆盖原图。两项参数旁的 `?` 鼠标悬停或键盘聚焦即可看解释：tile 是分块尺寸，越小越省显存；repeats 是再次放大的次数，1 次为 4×、2 次为 16×，像素与显存占用都会大增。
- **AI 扩图**：用当前 Qwen 组合做“扩展画布 → 参考图编辑 → 原图像素回贴 → 可选过渡带融合 → 校验”。新增 `strict`（默认，整块原图差异必须为 0）与 `feather`（仅在实际扩展的边缘建立 16/32/48 px 过渡带，核心区域差异仍必须为 0，未扩展边不参与融合，可选局部色调匹配）两种接缝模式。色调或羽化使边界指标变差时自动回退到更保守的结果，原因写入 manifest；feather 任务额外保存 `strict.png` 与“左严格 / 右融合”对照 `comparison.png`。256×256 左右各扩 64，实测 384×256、16 步 / CFG 6、约 50 秒；1984×1120 实测约 27 分钟。**这不是遮罩局部重绘，也不是整图重绘**；目前只在合成小图上验收，复杂照片、文字、人像与四向角落仍未完成实机验收，不能宣称普适无缝。默认值即为实测过的 16 步 / CFG 6。资源检查只作提示：内存/显存估计不足时扩图仍允许提交，失败或超时按任务失败处理；电池保护、模型文件缺失、显卡繁忙与运行时内存保护仍然生效。
- 两者初版只接受 8 bit 输入；16 bit 由后端明确拒绝。含 alpha 通道的图不再拒绝：明显透明像素（alpha < 250）占比不足 1% 时执行时直接丢弃 alpha（RGB 不变），否则合成到白底；采用哪种策略、透明占比与背景色会写进任务 manifest 的 `alpha` 字段。输入上限 25 MiB / 1600 万像素；放大不设固定输出上限，提交和执行前按当前内存、显存与磁盘预算判断；扩图输出上限单边 4096 / 1600 万像素；超时 30 分钟。
- 参数区直接写出最大范围，并在提交前显示预计输出尺寸、额外显存、系统内存和参考耗时；超过实测建议值只显示提醒、仍可提交，超过最大范围才禁用。实测建议：放大 8K UHD（7680×4320），扩图约 1984×1120（2.2 MP）。
- 取消排队任务立即生效；取消运行中的放大会结束独立放大进程并释放其模型。取消扩图仍等待原生采样结束并丢弃结果，不强行卸载 Qwen；扩图超时同样需要等待当前采样结束。电池保护与任务期间可用内存低于 3 GiB 则紧急停止相应进程。Qwen 模型在扩图后是否保留仍遵循「模型与显存」里的常驻设置，取消任务不会卸载用户保留的模型。
- 能力不是写死的：`configs/image-tools-verified.json` 绑定放大模型、`sd-cli.exe`、常驻放大的 `stable-diffusion.dll`、`sd-server.exe` 的 SHA256 与当前模型组合指纹；任一文件或设置变化都会自动回到「待本机验证」，扩图在更换模型组合后需要重新实测。该验收文件绑定当前机器，不随仓库提供。默认参数保存在 `configs/upscale.default.json`、`configs/outpaint.default.json`。
- 输入副本在 `data/image-tools/`；图片加密进私密库时，匹配的精确副本与描述文件会一并清理。任务运行记录、输出与哈希在 `outputs/{upscale|outpaint}/<任务 ID>/`。
- **不能提交时会说明原因**：生图、放大、扩图三个入口在条件不满足时按钮保持禁用，鼠标悬停（触屏可点按聚焦）会显示具体阻塞项，例如模型未配置或未加载完、电池保护、等待上次推理结束、队列已满、未勾选内容约定、输入为 16 bit、参数越界、能力待验证。含 alpha 的图片不阻塞提交，图片卡片会提前写明“丢弃 alpha”或“合成到白底”。生图按钮在未勾选内容约定时即禁用，不再等到提交后才报错。
- **实测性能上限（2026-10-23，独立测试）**：1080p → 7680×4320（8K UHD）约 29 秒、额外显存约 0.6 GB；8192×8192（67 MP）约 56 秒、约 40 MB PNG；tile 512 会因显存不足失败，且 CLI 会以退出码 0 写出未放大的原图（应用有尺寸校验）。扩图 1984×1120 需约 27 分钟、显存峰值 7.6/8.19 GB；3840×2160 在 VAE 编码后因系统内存低于 3 GB 被中止，**当前单次扩图路线达不到 4K**。网页已取消放大的固定输出上限，改为按当前内存、显存和磁盘预算放行（8K / 67 MP 仅作为实测参考），扩图保留 4096/1600 万像素的硬上限，并在界面显示 2K 实测建议和 4K 风险提醒。

验证：后端全量单测通过；前端 mock 界面检查 27/27、页面异常 0；真实服务已确认两个入口显示「本机已验证」且控制台无错误。生产图库尚未提交真实任务，避免测试图污染现有作品。

## 已实现

- **2026-10-23 常驻推理引擎**：模型不再随网页服务退出。引擎以 detached 方式启动，状态记录在 `data/engine.json`；关浏览器、关启动窗口、重启服务都不卸载，新服务会按 PID + 可执行路径校验后领养。电脑休眠不主动卸载，唤醒后探活，引擎无响应才结束它并禁止生成。手动卸载有两个入口：**任意页面侧栏「卸载模型」**，以及桌面 **卸载模型.cmd**（列出各组件的内存 / 显存占用，可单独卸载某个组件，服务没开也能用）。取消生成**不会卸载模型**（引擎无法中断采样，改为丢弃结果并等待其结束）；服务重启时正在跑的任务标记为已取消，请求参数写入 `data/interrupted/`。拔电仍按电池保护取消任务并卸载。详见 `MODEL_LIFECYCLE.md`。

- **2026-10-22 工作台组件控制**：工作台「创作设置」下方常驻「模型与组件 · 加载 / 释放」，提供扩散模型、文本编码器、VAE、视觉编码器的独立操作和权重内存 / 显存统计，也可加载或卸载整套模型。释放所选组件不影响其他组件，下次生成按需重新加载。加载中可取消并释放，生成或排队时禁用模型操作。新增系统内存 / 整卡显存实时条，手动卸载后保留本次服务运行期间最近一次退出前的进程占用记录。进程显存无法读取时明确显示「未能读取」，不把整卡变化算作模型释放量。关闭 / 刷新网页不会取消后台任务，重开可查看进度；关闭启动窗口、停服务或电脑断电会中断生成，服务重启后将未完成任务标记为中断，不自动重试。后端修改需重启服务生效。

- 中文创作工作台，深色 / 浅色主题，手机与桌面布局；模型、尺寸、步数、采样等精细参数默认收起，提示词与画面比例优先展示。
- 工作台内置 DeepSeek 创作助手：配置 API 地址 / 模型 / 密钥后流式对话，支持停止、清空，回复中的提示词可一键填入画面描述。可在消息里附加图片（PNG / JPEG / WebP，≤25 MB）：后端转成 JPEG（长边 ≤1536）以 base64 data URL 随消息发送，用于让助手分析画面或反推提示词。对话区独立滚动：滚动条常显、可拖拽边缘调高，向上翻看时出现「回到底部」；输入栏右侧的圆环显示上下文占用（按本地单次上限 60000 字估算，悬停可看字数与 token 估算）。每次请求都会把 `prompts/system.md` 作为 `system` 消息放在最前面，并在其后附加一段**运行时参数快照**（模型文件、大小、运行设备、显存预算、默认采样参数、显卡、是否已加载）；文件可直接编辑，保存后下一次请求立即生效，删掉则回落到内置默认提示词。当用户要求「参数分析」或「输出参数」时，助手按快照逐项回答。密钥默认只驻留服务进程内存；勾选「记住密钥」后用 Windows DPAPI（当前用户作用域）加密写入 `data/assistant.key`，明文不落盘。浏览器只与本地后端通信，由后端转发请求。
- 模型页支持「手动加载组合」：指定扩散模型 / 文本编码器 / VAE 路径，文本编码器、VAE 可选 CPU 或 CUDA0，扩散模型使用 CUDA0。新增「**预加载权重到内存**」开关（`--eager-load`）：开启后在加载阶段读取权重；关闭时先创建上下文，首次使用时再读权重。加载过程中可取消并释放，加载完成后可「**卸载整套模型 · 释放内存 / 显存**」，画布底部也有快捷卸载。模型页分别显示权重文件体积、计算设备、推理进程物理内存 / 私有提交量 / 显存，以及系统可用内存、整卡显存。Windows WDDM 不提供进程显存时显示「未能读取」。可将组合及预加载开关保存为预设（`data/profiles.json`），也可填写自定义启动参数。**已支持四类组件独立加载 / 释放权重**，显示各组件实际权重缓冲区内存 / 显存；计算缓存与共享上下文不全部按组件分摊，详见 `MODEL_LIFECYCLE.md`。
- 提示词、反向提示词、参考图上传、Q6/Q4 切换、宽高、种子、步数、CFG、采样器、调度器、批量与 VAE 分块参数。**提示词可留空**（留空时画面完全由模型决定）。尺寸可任意填写 256–4096，界面提示优先用 8 的倍数，非 8 的倍数会自动向下对齐（如 1003 → 1000），后端同样兜底对齐。
- 本地图片扫描、缩略图、搜索、收藏 / 取消收藏、喜欢、不喜欢、隐藏、回收站与恢复。图库图片悬停或键盘聚焦时，图片底部直接滑出三列完整操作栏：收藏、喜欢、不喜欢、查看详情、画布预览、加入 / 取消比较、复用参数、下载原图、导出配置、隐藏 / 取消隐藏、加密、移入回收站。无需点击「更多」或先打开操作弹窗，悬停不改变卡片位置。触屏和宽度不足 220px 的卡片直接在图片下方显示全部按钮，窄卡片使用两列。16 bit 原图额外显示导出 8 bit 副本，回收站卡片保留恢复入口；移入回收站仍需确认，加密沿用现有密码流程。支持键盘聚焦与执行，图片操作与详情页共用同一套入口。再次点击已选标记可取消，沿用单一标记规则（收藏、喜欢、不喜欢互相替换），支持「喜欢」筛选；新增喜欢标记需重启网页服务生效。画布预览支持 **‹ › 左右切换**（也可用键盘 ← →），底部显示「当前 / 总数」；预览左下角「**属性**」按钮就地展开这张图的全部参数（文件、提示词、采样参数、模型、生成记录），可一键复制为文本或跳到完整详情。
- 图片详情显示可解析的生成配置、耗时（原图有记录时）、文件时间与 SHA256，保留原始 PNG 元数据；支持导出 JSON、回填参数和 2–4 张图片比较。
- 创作参数自动保存为当前浏览器、当前网页地址下的本地草稿，刷新恢复提示词、尺寸、采样参数、色深、确认勾选和已上传参考图选择；恢复不提交任务，也不操作模型。密码与 API Key 不属于草稿字段。可用「保存参数」另存预设；浏览器数据被清理会丢失草稿。
- 参数预设持久化存储、应用和删除，载入 / 删除预设只处理参数，不提交生成任务；生成入口校验提交按钮。界面上「保存参数 / 载入参数」并排放在提示词下方，载入时弹出预设列表（含删除）。复用历史参数时仍需核对模型文件和原始输入图。
- 模型路径与文件检查，实时显存和 GPU 利用率，完整模型上下文预加载 / 卸载接口、显存预算、CPU 卸载选项。
- 原生推理服务适配、单队列逐张生成、取消（取消运行中的任务会结束其独占推理进程并释放整套模型；已保存图片保留，排队任务可单独取消）、真实步数与耗时、失败记录、完成后自动 PNG 配置与 JSON/SHA256 侧文件保存。**2026-10-21 首次真机生图通过**：Q4_K + `Qwen3VL-8B-Instruct-Q4_K_M.gguf`（文本编码走 CPU）+ 专用 VAE，512×512 / 8 步耗时 233 秒（首步条件编码约 3.5 分钟，之后每步约 3 秒）。
- 生成任务卡片显示**预计总耗时 / 预计剩余时间**（有匹配历史时）和**当前图片预计采样剩余时间**（有实际步速时），随任务轮询每 3 秒更新。总耗时取最近最多 5 次相同配置成功任务的中位数，区分提示词、参考图、模型文件及修改时间、分辨率、步数、批量、CPU / GPU 设置、模型是否已加载与 SHA256 缓存状态；种子不参与匹配。历史从本功能启用后积累并随任务记录保存，旧记录不补造。采样估算排除首个进度点之前的编码 / 预热时间，按最近最多 8 段实际步速动态更新，批量逐张重置。排队、加载、编码、解码 / 保存阶段给出说明；无数据或进度停滞时不显示虚假的倒计时。采样预估不含解码、保存或后续图片；总耗时不含排队等待，其他程序占用及缓存变化仍会影响准确度。
- 私密库为**本地全加密**：AES-256-GCM + scrypt（N=2^17, r=8, p=1），图片、配置与待清理清单一起加密。加密文件写入并回读校验通过后，才删除明文原图、同名配置 JSON、缩略图、预览图和回收站副本，删除图库记录后再 VACUUM。**密码只需设置一次**：用当前 Windows 账户的 DPAPI 加密保存在 `data/vault.key`，之后加密和查看都是点一下，不再反复输入；`.qvault` 文件本身仍只认这条密码，拷到别的电脑或别的账户打不开。可随时「更换密码」（全部文件重新加密）或「清除保存的密码」（之后恢复手动输入）。解锁内容只在内存预览，关闭或切到后台即清除。旧版「只存加密副本」的数据需在私密库执行一次性统一密码升级，详见下文「私密库（本地全加密）」。
- 应用仅绑定回环地址，并校验 Host、同源请求与写操作会话令牌。

## 当前边界

1. **生图链路已跑通，但显存吃紧**：文本编码器用 Qwen3VL-8B-Instruct GGUF，Q6、Q4、VAE 及扩图 LoRA 均位于本项目的 `models/`。若 ComfyUI 同时运行（实测占用约 6 GB 显存），8 GB 卡只剩约 2 GB，必须依赖 CPU 卸载，512×512 单张也要数分钟；关闭 ComfyUI 后可用 Q6_K。参考图编辑所需 `models/mmproj-Qwen3VL-8B-Instruct-F16.gguf` 已下载（1,159,029,824 字节，约 1.16 GB），通过官方 SHA256 校验；记录见 `downloads/mmproj-verified.json`，可用 `scripts/download_mmproj.py` 重新下载 / 校验。本机当前设置已指向项目内的视觉编码器。
2. 原生运行库固定为 stable-diffusion.cpp `0518b34`；依据[固定版本上游 API](https://github.com/leejet/stable-diffusion.cpp/blob/0518b34/examples/server/api.md)接入。上下文就绪不等于所有权重已经读取；预加载开关用来提前读取权重。**引擎同一时间只有一个 context**，支持分别管理组件权重；整套卸载才会释放共享上下文。默认使用 `--offload-to-cpu` 将权重放在系统内存，GPU 计算时按需传输；运行设备不等于权重存放位置。8 GB 显存不能同时容纳 Q6、编码器和所有计算缓冲区，因此提供 VAE / 编码器 CPU 计算选项与显存预算。Windows 可以换出内存页，预加载也不保证永久物理驻留。
3. 边界页记录实际生成任务结果；尚未开展自动分辨率压力测试，也没有声称当前硬件可运行 4096×4096。界面 4096 上限只是输入校验范围。
4. 助手只在页面内收发文字与**你主动附加的图片**；对话不落盘，刷新即清空。**附加的图片会随请求发送到 DeepSeek**（本机先缩放为 JPEG），生图图库里的其他图片不会被自动上传。图片仅在用户消息中允许，单次对话最多 8 张、单图 ≤25 MB。密钥可只存内存，也可用 DPAPI 加密保存到本机（仅当前 Windows 用户可解密；换账户或拷到其他电脑都解不开，但同一账户下的恶意程序仍可借用解密）。可用性、计费与上游审核取决于 DeepSeek 账户本身，本版本未接入本地模型。
5. 私密库升级完成后**磁盘上只保留 `.qvault` 加密文件**：明文原图、同名 JSON、缩略图、预览图与回收站副本都在新密文回读校验通过后删除，图库记录删除后再 VACUUM。无法用任何已知密码解开的旧文件保持加密保留、不能在页面查看，也不计入待升级数量。**密码保存在 `data/vault.key`，由当前 Windows 账户的 DPAPI 加密**：同一账户打开工作台后点一下即可查看，这是本机便利性的取舍；`.qvault` 拷到别的电脑 / 账户仍打不开。忘记密码无法恢复；升级会删除旧密码本，换机或重装前请自行记住密码。仍不处理应用之外的副本 / 备份，也不保证抹除系统缩略图缓存、回收站历史或磁盘残留。
6. 内容约定已按用户 2026-10-22 的最新要求调整：本地应用不再限制成人内容，保留极端血腥和欺骗用途的约定。网页确认文案、生图接口词项检查与助手提示词已同步更新；DeepSeek 服务自身的审核规则不受本地设置影响。当前**没有语义审核或生成结果分类器**，不保证自动识别所有违规内容。
7. 历史图片缺少的信息显示“未记录”，不会推算虚假的生成耗时。新图保存软件/模型/输入哈希与请求配置，但跨引擎、跨硬件仍不能保证逐像素相同。
8. 同步 SHA256 首次读取完整模型可能耗时；界面显示单独阶段。私密库加密单文件上限 128 MiB；参考图上传上限 25 MiB。
