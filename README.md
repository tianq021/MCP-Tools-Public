## 使用范围

这是开发源码快照。游戏桥接依赖对应游戏版本、加载器和本机路径。模型服务需要自行准备模型与运行环境，飞书服务需要自行配置凭据。源码中的示例盘符应按部署环境调整。部分历史工具仅收录源码组件，原工程用到的第三方资源、构建工具、运行数据及部分本机专用模块需另行准备。

现有独立项目包括 [InfectionFreeZone-MCP](https://github.com/tianq021/InfectionFreeZone-MCP)、[After Inc Trainer](https://github.com/tianq021/after_inc_trainer)、[Broforce Life Trainer](https://github.com/tianq021/broforce_life_trainer)、[Borderlands 3 Trainer](https://github.com/tianq021/Borderlands3Teainer)、[Infection Free Zone Trainer](https://github.com/tianq021/InfectionFreeZoneTrainer)、[new_fastgpt](https://github.com/tianq021/new_fastgpt)、[new_tianq](https://github.com/tianq021/new_tianq) 和 [Qwen2.1imgQ6](https://github.com/tianq021/Qwen2.1imgQ6)。
