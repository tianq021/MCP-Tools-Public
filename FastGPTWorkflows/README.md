# FastGPT 工作流 JSON 资料与节点分析

围绕 FastGPT 工作流 JSON 的规则整理、模板复用和节点分析资料库，帮助使用者理解节点配置，并为 AI 辅助生成、检查和修复工作流提供参考。

**当前统一入口是 [`fastgpt_发布包/`](fastgpt_发布包/)**；第二批整理资料位于 [`new_fastgpt_clean_core/`](new_fastgpt_clean_core/)；节点分析入口位于 [`new_test_json/`](new_test_json/)。

仓库交付内容以 Markdown、JSON 和说明文件为主，可直接浏览或下载使用。它没有统一的应用启动、依赖安装或构建命令；使用工作流模板时，需要自行准备 FastGPT 环境。

## 这个项目可以帮助你做什么

- **理解节点**：区分节点用途、用户可填写项与平台内部字段，按需求选择节点。
- **参考 JSON 结构**：查看节点输入输出、变量引用、连线和聊天配置的组织方式。
- **复用工作流母版**：从文件上传、表单、分支、循环、消息推送等模板开始组合流程。
- **辅助 AI 生成与修复**：将相关规则、补丁和母版作为上下文，减少凭空猜测字段。
- **定位常见问题**：对照自检清单排查导入、变量传递、代码节点和自动执行配置。

2. [文件等级与读取规则](fastgpt_发布包/fastgpt_完整资料/fastgpt/00_给AI看的_FastGPT文件等级与读取规则_2026-05-19.txt)：了解规则、补丁和母版之间的关系。

`old/` 保存历史资料；遇到同一问题的不同说法，应核对文件日期和修订说明，优先采用较新的适用规则。外层文件还保留了原始发布批次的实验包说明，阅读当前仓库资料可直接进入上述已展开目录。

## 使用模板的基本流程

1. 明确输入、输出、分支条件，以及需要调用的模型或外部服务。
2. 阅读对应规范和补丁，选择接近需求的母版。
3. 修改或生成 JSON，检查节点 ID、变量引用、连线和节点输入输出是否一致。
4. 导入自己的 FastGPT 环境，选择模型、知识库、应用或插件，补齐必要配置。
5. 使用少量输入验证正常路径与分支，再验证文件、循环或外部服务调用。

模板覆盖文件上传总结、表单输入、用户选择分支、批量循环、数据库连接、企业微信／钉钉／飞书推送、变量更新、工具调用和网页抓取等结构，具体文件见 [模板索引](new_fastgpt_clean_core/docs/05_模板索引.md)。

模型、知识库、插件和服务连接配置依赖目标环境。不要照抄其他环境的资源 ID，也不要将真实 API Key、Token、密码或 Webhook 写入公开 JSON。JSON 语法校验通过不等于已在目标环境中运行通过。

## 反馈与维护

反馈问题时，请提供所用资料或模板的相对路径、FastGPT 版本、复现步骤、预期行为与实际结果，并附脱敏后的报错或最小 JSON。

更新规则时注明适用范围和依据；更新模板时说明是否完成 JSON 检查、平台导入及实际运行验证，便于读者判断可复用程度。
