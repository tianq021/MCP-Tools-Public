# 文明6 + Gemma4 本地接口

默认模型是本机已有的 **`gemma4:e4b`**。独立客户端只配置本地 Ollama，不配置付费模型。模型实际运行消耗本机内存和显存。

Gemma4 支持思考模式。本入口已修正此前错误的“不支持推理”声明，默认使用 `medium`；界面可选关闭或中等。这里的“中等”用于打开思考，不代表已验证多档推理强度。请求用 `reasoning_effort=medium` 开启、`none` 关闭；实际推理输出尚待测试。输出上限为 4096，以给思考和回答留出空间。已有聊天若保留了关闭选项，刷新后手动改为“中等”，或新建聊天。

## 使用

1. 结束当前其他游戏后，手动启动《文明6》，进入一个单人对局。
2. 双击同目录 **`启动文明6本地AI.cmd`**。它启动本地 Ollama 服务和独立 DSH 网页，并打开浏览器。
3. 创建聊天，确认预设为 **文明6 · 本地模型**、模型为 **Gemma4 E4B**。工作目录可选本文件夹。
4. 先发送：**“只读取当前回合、城市和单位，先不要操作。”**
5. 读取成功后，再发送：**“接管一个回合，完成后停下，简短报告操作。”**

启动器本身不启动游戏、不提交模型请求。网页关闭后后台服务仍会运行。以后再次双击会复用本入口的服务。

- 独立客户端端口：`127.0.0.1:3096`；独立配置：`dsh-home/profiles/web/cordis.patch.yml`。

- 保留原有 DSH、修改器及游戏文件。当前游戏用户设置已启用 `EnableTuner=1`，本次无需修改。
- `upstream` 是上游源码参考副本，运行时不依赖它。上游项目：https://github.com/lmwilki/civ6-mcp 。

为了减少小模型提示词负担，模型只看到查询目录、查询参数、执行操作三个 MCP 工具；71 项实际游戏工具按需查询。工具初始 JSON Schema 从原完整接口的约 73,455 字符降到 1,442 字符；这不是完整提示词长度，也不是速度实测。

入口关闭了 MCP 的自动启动游戏、后台关闭弹窗和镜头控制任务。只有明确的工具调用才会请求游戏状态或操作。游戏工具仍可改变对局，先用查询提示进行验证。

## 排查

- 提示无法连接游戏：确认《文明6》已进入对局；不要同时让 FireTuner 或另一个 Civ6 MCP 占用游戏调试连接。
- 提示 Ollama 无法连接：检查 `runtime/logs/ollama.stderr.log`；确认没有其他服务占用 11434。
- 模型加载慢、显存不足：先退出其他大型游戏；可临时在此独立客户端选择 `qwen3:1.7b`，但其游戏决策能力也尚未验证。
- 3096 被其他程序占用时启动器会停止；不要关闭原有 3080 客户端来解决。

开发检查：`probe_mcp.py` 检查接口协议；`probe_client.py` 只读检查专用客户端；均不提交模型请求、不操作游戏。
